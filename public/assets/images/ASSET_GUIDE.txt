CYBER ABYSS — ART INTEGRATION HANDOFF
All image paths below are served from /assets/images/. See asset-manifest.json for every file, dimensions, animation and owner action.

ARTWORK
15 original SVGs, no external references, fonts, scripts or linked images inside SVG.
Native canvas 480x800. SVG viewport sizes are explicit.
Artwork follows existing cyan / purple / pink UI; only hazards use bright red.
Transparent images have no background rectangle. Collision remains rectangular regardless of alpha.

Replace Player rectangle with scene.add.sprite(x,y,'runner-idle'); physics.add.existing(sprite).

  right image at (x+W/2-8,y-8), origin(0), native 8x16.

Use multiple pointers and persistent left/right intents read by Player.update alongside keyboard.

HUD / SCALING
Approved compact HUD: x16,y16,448x64, bottom80.
Player spawn x240,y100; 24x24 body top88. Gap is now 8 game px.
No spawn, camera or physics change. Moving gameplay can still pass behind a HUD; owner may decide on a gameplay-safe top margin later.
Existing config Phaser.Scale.FIT + CENTER_BOTH already preserves aspect ratio 480/800.
CSS decorates desktop gutters; canvas stays centered, full visible height, never stretched.
Buttons 348x60 game px -> 261x45 CSS px at 360px wide portrait.
Browser viewport checks are not a substitute for a physical touch-device test.
